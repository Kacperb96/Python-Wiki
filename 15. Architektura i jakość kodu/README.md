# 15. Architektura i jakość kodu

To dział o tym, jak zbudować kod, który nie tylko działa, ale daje się rozwijać przez lata.

Po tym dziale powinieneś rozumieć:

- code smells,
- refaktoryzację,
- architekturę warstwową,
- separację logiki biznesowej,
- dependency injection,
- SOLID,
- wzorce projektowe.

To sekcja bardziej dojrzała i projektowa, najlepiej czytać ją po webie, bazach i testowaniu.
