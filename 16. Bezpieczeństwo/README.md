# 16. Bezpieczeństwo

To końcowy dział ścieżki, bo łączy wcześniejsze elementy: API, bazę, pliki, procesy i architekturę.

Po tym dziale powinieneś rozumieć:

- podstawy bezpieczeństwa aplikacji Python,
- walidację danych,
- sekrety i env vars,
- bezpieczne użycie `subprocess`,
- SQL injection i command injection,
- path traversal,
- bezpieczną serializację.

Czytaj po kolei, bo materiał przechodzi od zasad ogólnych do konkretnych klas ryzyk.

Co dalej:

- wracaj do całego repo jak do referencji
- możesz też rozważyć budowę własnych projektów przekrojowych opartych o te materiały
