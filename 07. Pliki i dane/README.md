# 07. Pliki i dane

To dział mocno praktyczny: jak czytać, zapisywać i przetwarzać dane w codziennej pracy.

Po tym dziale powinieneś umieć:

- pracować z `open()`,
- rozumieć `utf-8`,
- rozróżniać tekst i bajty,
- używać `pathlib` i `os`,
- pracować z `json`, `csv`, `configparser`, XML,
- korzystać z `sqlite3`.

Czytaj po kolei od prostych plików tekstowych do bardziej strukturalnych formatów i bazy danych.
