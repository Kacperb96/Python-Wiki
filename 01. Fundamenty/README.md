# 01. Fundamenty

Ten dział jest punktem startowym całego projektu.

To nie ma być tylko szybkie "wprowadzenie", ale baza, na której później zrozumiesz:

- funkcje,
- moduły,
- kolekcje,
- programowanie obiektowe,
- pliki,
- testowanie,
- web i API.

Jeśli fundamenty są słabe, to każdy kolejny temat zaczyna wyglądać na trudniejszy, niż naprawdę jest.

---

## Co powinieneś zrozumieć po tym dziale

Po przejściu całego folderu powinieneś rozumieć:

- czym są zmienne i typy danych,
- jak działają stringi,
- jak działają operatory arytmetyczne, porównania i logika,
- jak budować warunki i pętle,
- czym jest `None`,
- jak działa truthy/falsy,
- jaka jest różnica między `==` i `is`,
- jak używać `enumerate`, `zip`, `sorted`, `any`, `all`,
- czym jest unpacking,
- jak działa zasięg zmiennych i zasada LEGB,
- jak obsługiwać wyjątki.

## Jak się uczyć z tego działu

Najlepsza kolejność pracy:

1. przeczytaj jeden plik,

3. zrób 2-5 własnych mikroprzykładów,

## Po czym poznać, że fundamenty są opanowane

Dobry znak to sytuacja, w której potrafisz bez większego stresu:

- napisać prosty program z `if`, `for`, `while`,
- przetwarzać tekst wejściowy,
- odróżnić `None` od pustego stringa,
- wyjaśnić różnicę między `==` i `is`,
- napisać prostą funkcję z `try/except`,
- rozumieć, czemu jakaś zmienna działa w funkcji, a poza nią nie.
